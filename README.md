# JSON Data Processor

## 1. Objective
Read student information from a JSON file and perform searching, filtering, and summary operations using Python.

## 2. Tools Used
- Python
- json module

## 3. Input and Output
- Input: `students.json`
- Output: `results.json`
- The program searches students by name, filters students based on marks, and calculates total, average, highest, and lowest marks.

## 4. How to Run
1. Keep `json_processor.py` and `students.json` in the same folder.
2. Open the terminal in that folder.
3. Run:
   `python json_processor.py`
4. The processed results will be saved in `results.json`.
